# Ahmed Design - موقع خدمات التصميم الجرافيكي ومعرض الأعمال

موقع محفظة وخدمات التصميم الجرافيكي لـ **أحمد (Ahmed Design)**، مصمم بالكامل داخل **4 ملفات فقط وبدون أي صور خارجية**:

## 📁 هيكل المشروع (4 ملفات فقط ومكتفية ذاتيًا):
1. `index.html`: الصفحة الرئيسية للموقع، تحتوي على الهيكل والمحتوى، معرض الأعمال، كروت الخدمات، استمارة طلب التصميم، بالإضافة إلى **دمج جميع الصور (صورة البروفايل و4 أعمال جرافيك) بصيغة Base64 مشفرة داخلياً** بدون الحاجة لأي ملفات صور خارجية.
2. `style.css`: ملف التنسيق والمظهر العصري (Dark Mode + Glassmorphism + Cairo Font).
3. `script.js`: ملف البرمجة والتفاعلات، التمرير السلس، وإرسال البيانات إلى البريد الإلكتروني.
4. `README.md`: ملف التوثيق والتعليمات وتفاصيل التواصل.

## 🖼️ معرض الأعمال المدمج داخل index.html:
1. **إعلان حليب العين الطازج**: تصميم دمج وإضاءة متقدم لمنتج ألبان وكتابة 3D.
2. **إعلان كادبوري ديري ميلك**: تصميم منتج سوشيال ميديا بألوان نيون بنفسجية عصرية.
3. **مصغرة يوتيوب - فخ الذكاء**: تصميم مصغرة قناة يوتيوب سينمائي عالي النقرات (High CTR).
4. **حملات بوستات السوشيال ميديا**: تصاميم عروض وتخفيضات وتسويق إلكتروني.
